# BeaverAndCalf

Простой Telegram-бот для публикации добрых мини-комиксов про бобра и телёнка. Проект не копирует бренды, логотипы или конкретных персонажей и рассчитан на собственные изображения.

Сейчас репозиторий принимает готовую картинку и отправляет её в Telegram. Генерация изображений и платные API намеренно не подключены.

## Структура

- `content/latest.jpg` — текущая картинка для публикации;
- `content/caption.txt` — подпись к картинке;
- `src/send_to_telegram.py` — независимый слой Telegram-отправки;
- `archive/` — место для будущих публикаций, например `archive/2026-10-03.png` и `archive/2026-10-03.txt`.

JPG-файл нельзя надёжно создать как placeholder автоматически, поэтому добавьте собственную картинку вручную по адресу `content/latest.jpg`. После этого workflow сможет отправить её.

## Секреты GitHub

В репозитории откройте `Settings → Secrets and variables → Actions` и создайте:

- `TELEGRAM_BOT_TOKEN` — новый токен бота;
- `TELEGRAM_CHAT_ID` — числовой ID группы.

Не коммитьте токен, не вставляйте его в код и не передавайте его в чат или issue. Если токен был раскрыт, отзовите его через @BotFather и создайте новый.

Бот должен быть добавлен в группу и иметь право отправлять сообщения. Username группы сам по себе не заменяет числовой `TELEGRAM_CHAT_ID`.

## Как изменить подпись

Отредактируйте `content/caption.txt`, сохраните изменения и отправьте их в ветку `main`. Пример:

```text
Любовь — это быть рядом даже в самый обычный день. 🦫❤️🐮
```

## Запуск

Workflow `Send comic to Telegram` запускается вручную через вкладку `Actions → Send comic to Telegram → Run workflow`.

Он также запускается автоматически при изменении в `main` одного из файлов:

- `content/latest.jpg`;
- `content/caption.txt`.

Каждый запуск устанавливает Python 3.12, ставит `requests` и выполняет `python src/send_to_telegram.py`. Скрипт использует официальный Telegram Bot API `sendPhoto` и multipart upload файла, а не публичную ссылку.

## Архитектура на будущее

Компоненты разделены по ответственности:

```text
идея сюжета → генерация изображения → content/latest.jpg → GitHub Actions → Telegram
```

Позже можно добавить отдельный workflow или скрипт генерации, который будет только создавать `content/latest.jpg` и не будет знать детали Telegram. Старые изображения и подписи можно сохранять в `archive/`.
